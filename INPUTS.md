# Input files and formats

Shared-config scripts resolve these files relative to `ATAC_PROJECT`. Inputs are supplied separately; no study data are bundled.

| File | Format / content |
|---|---|
| `input_bam/input_atac_rep{1,2}_{time}.sorted.bam` | Filtered, coordinate-sorted BAMs and indexes; time = 0h, 1h, 3h, 6h, 12h, 24h |
| `input_consensus_peaks.bed` | BED4 or more: chromosome, start, end, stable peak ID |
| `input_peak_annotations.xlsx` | Final annotated Wald result workbook. Sheet 1: peak_id, chr, start, end, TSS, matched_gene, enhancer, log2FoldChange, padj. Sheet 2 / `260322_1h_3h`: log2FoldChange_1h, padj_1h, log2FoldChange_3h, padj_3h and the same annotations |
| `input_fig6_peak_annotations.xlsx` | Dedicated Figure 6 workbook; sheet `260322_1h_3h`, same time-specific schema |
| `input_wald_tss_1h.csv`, `input_wald_tss_3h.csv` | First column = peak identifier, then DESeq2 result columns and `gene`. The Wald script's TSS outputs include the `gene` column; stage them under these input names |
| `supplementary_tables/input_tss_groups.xlsx`, `input_enhancer_groups.xlsx` | Supplementary group tables, first row skipped: `Peak ID`, `Cluster`, `Gene`, `Log2FC (1h)`, `Log2FC (3h)`; T1–T4 or E1–E4 |
| `input_rna24h_deseq2.csv` | First column = FlyBase gene ID; DESeq2 `log2FoldChange`, `padj`, etc. The RNA script's first `gene` column is the row identifier when read by the J.Y.H. scripts |
| `input_representative_tss.bed` | Representative TSS reference generated by `06_annotate_peaks.py` from the longest genomic transcript span per gene; BED6 with gene in column 4 and strand in column 6 |
| `input_dm6_transcripts.bed` | UCSC RefSeq BED12; exon lengths/offsets in columns 11/12 |
| `input_dm6.chrom.sizes` | dm6 chromosome lengths |
| `input_transcript_downstream_3kb.bed` | BED6, 3-kb transcript downstream regions |
| `input_annotated_enhancers_dm6.bed` | Lifted dm6 enhancer annotations |
| `input_intergenic_reference.bed` | Original filtered intergenic BED6, used to verify the region set and preserve row order |
| `input_box_peaks.csv` | Boxed peaks of Figure 1C/D, including `peak` and `gene`; ChIP-seq positive-control summary input |

Worksheet names and column names are part of the supplied schemas and are retained even where the workbook filename is generalized. `TSS` uses `O` / `X`; `matched_gene` and `enhancer` hold the source gene assignments. The c-means CSV outputs and formatted supplementary Excel inputs are different formats: the Excel tables must be supplied in the stated schema.

Generated RPGC tracks and shifted BAMs are read directly from `ATAC_OUT/00_preprocessing/bigwig/`. The other generated Figure intermediates are read from their producing script's output directory. External download scripts create local `input_*` files below `ATAC_PROJECT/public_data/`; their URLs retain the original public filenames.

Command-line scripts accept their own `input_*` arguments; see [RUNNING.md](RUNNING.md) and each script's usage line. Genome assembly, chromosome naming, peak identifiers, row order, gene annotations and result-table column meanings must match the supplied source analysis.

## Transcript annotation and GO inputs

`01_peak_processing/06_annotate_peaks.py` accepts `input_transcripts.tsv` with `gene_id`, `transcript_id`, `length`, `chr`, `start`, `end`, `strand`. Transcript coordinates are 1-based inclusive and `length = end-start+1` (genomic span, as in the source reference). The longest row per gene is retained; ties retain input order. The stored selected-longest-transcript table can also be supplied directly. Gene symbols such as `NA` are retained as text.

The consensus BED contains chromosome/start/end/peak_id. The script produces representative and active TSS BEDs, TSS/distal annotations, 10-kb distal links, and a TSS-peak CSV for the Wald script. With the two optional Wald result arguments it also writes the final annotated Excel workbook. Existing Wald statistics are preserved. The workbook can be staged as `input_peak_annotations.xlsx`; Figure 6 continues to use its separately selected `input_fig6_peak_annotations.xlsx`.

`Fig3/cluster_GO.R` accepts a **headerless, tab-separated, two-column** file: gene symbol first, group label second. Semicolon-delimited genes are split, and each group is deduplicated. Convert any source file with `cluster,gene` order to this schema before running. The same script accepts TSS or enhancer group lists, with a title label as its optional third argument.
